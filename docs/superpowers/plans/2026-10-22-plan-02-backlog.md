## Known gaps accepted for v0 (documented in code or docs)
- Interaction styles driven by JavaScript events are invisible to forced pseudo-states; focus is cross-checked with real focus, hover is worth-a-look only.
- Text contrast is judged on interactive elements only, and skipped (never guessed) over images, gradients, translucent layers, overlapping siblings, descendant-painted text and off-viewport elements; wide-gamut text is judged by the sRGB colour Chromium paints.
- The Tab walk cannot see traps inside custom elements, native multi-part controls or iframes (exempt by design), nor focus marks drawn inside a closed shadow root.
- The observer buffer takes a same-document navigation that lands on the requested URL for the commit (a same-URL reload, or a redirect whose last hop is the page being left); harmless in the crawl sequence.
- Contrast on Tailwind 4.3 focus rings (`lab()` colours) is not judged yet; `role=switch` checkboxes are judged for target size; exempt undersized targets still contribute circles to the spacing test.
- A page with no opaque background is judged against the white canvas only when nothing asks for a dark one (root `color-scheme`, a `color-scheme` meta tag or a dark preference keep the `never-opaque` skip); a focus mark set by script is found by the real-focus cross-check but hover feedback set by script is still invisible (worth a look only).
- The benchmark harness that publishes precision and recall numbers is plan 04; the end-to-end suite asserts 10/10 seeds found and 0/3 controls flagged (and measured) on the bench app.
